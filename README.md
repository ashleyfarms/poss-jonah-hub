# Poss Jonah Hub

Umbrella landing for Albert Jones’s “best of” food ranking family, hosted by Poss Jonah.

- **Live:** [Best Tea](https://tea.possjonah.com) — Southern iced tea rankings
- **Coming soon:** Pizza, BBQ, Fried Chicken, Seafood, Burrito, Taco, Egg Roll (national when they launch)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Netlify SPA (`netlify.toml`). Apex DNS for possjonah.com is managed separately.
